Compression （座標圧縮 × 二分探索）

要素数 N = 5

💡 座標圧縮（Compression）とは？

与えられた数列 A の各要素を、「全体の中で小さい方から何番目か（1始まりの順位）」に変換する操作です。
同じ値の要素は同じ順位になります。大小関係を完全に保ったまま、コンパクトな整数列 B へ変換します！

元の配列 A (元の値) N = 5

元の値は非常に大きい値（最大 $10^9$ など）も含まれます。

最小値: - 最大値: -
圧縮後の配列 B (1始まりの順位) 範囲: 1 ～ 4

大小関係を保ったまま、1からの連続する整数にギュッと圧縮！

✨ どんなに元の数が大きくても、最大順位は「ユニークな値の個数以下」になります。

💥 なぜそのまま配列の添字にしてはいけないのか？

競プロでは「数値 $X$ が何回出現したか」や「区間 $[L, R]$ の総和」を計算するために、値をそのまま配列のインデックスにする手法（バケット配列や累積和、いもす法、セグメントツリーなど）を頻繁に使います。
しかし、この問題のように値が A_i ≤ 10⁹ (10億) になると、致命的な問題が生じます。

✨ 競技プログラミングの鉄則: 「重要なのは値そのものではなく、大小関係」

数列の中に $10^9$ や $10^{18}$ といった巨大な数が含まれていても、登場する数値の種類は高々 $N$ 種類（$10^5$ 個）しかありません。
「値の大小関係（何番目に大きいか・小さいか）だけが必要」な問題では、座標圧縮によって $1 \sim N$ のコンパクトな整数に置き換えることで、
配列の添字として使えるようになり、いもす法やセグ木などの高速アルゴリズムと合体可能になる
という絶大なメリットが生まれます。

模範解答コード (A15)

C++ の `std::lower_bound` または Python の `bisect_left` による定石実装です。

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    if (!(cin >> N)) return 0;

    vector<int> A(N);
    for (int i = 0; i < N; i++) {
        cin >> A[i];
    }

    // 1. A をコピーしてソート
    vector<int> T = A;
    sort(T.begin(), T.end());

    // 2. 重複を削除してユニーク化 (erase + unique)
    T.erase(unique(T.begin(), T.end()), T.end());

    // 3. 各要素 A[i] が T の何番目かを二分探索 (lower_bound) で特定
    for (int i = 0; i < N; i++) {
        // lower_bound は A[i] 以上の最初のイテレータを返す
        auto itr = lower_bound(T.begin(), T.end(), A[i]);
        // 0-indexed の位置に +1 して 1-indexed の順位にする
        int rank = (itr - T.begin()) + 1;

        cout << rank << (i == N - 1 ? "" : " ");
    }
    cout << "\n";

    return 0;
}
import sys
import bisect

def main():
    input = sys.stdin.read
    data = input().split()
    if not data:
        return

    N = int(data[0])
    A = [int(x) for x in data[1 : N + 1]]

    # 1 & 2. 重複を取り除いて昇順にソートした辞書リストを作成
    T = sorted(set(A))

    # 3. 各 A[i] について二分探索 (bisect_left) で順位を求める
    B = []
    for a in A:
        # bisect_left は a の挿入位置 (0-indexed) を返すため +1 する
        rank = bisect.bisect_left(T, a) + 1
        B.append(str(rank))

    print(" ".join(B))

if __name__ == "__main__":
    main()
